# PagePath · 网页一笔画

**The webpage is the level. 网页就是关卡。**

PagePath 是一个桌面浏览器扩展：把当前网页的留白变成一笔画关卡，文字、图片和按钮成为需要绕开的障碍。按住毛笔，从砚台出发，经过所有墨点，最后抵达纸张。

**v1.0.0** · 适用于桌面 Chrome / Edge · 无需账号、服务器或构建步骤

## 特点

- **当前网页，即开即玩**：根据可见内容生成节点和可行路线，同一页面也能不断换图。
- **静态画面**：开始时定格当前视口，网页动画和后台内容更新不会移动本局地图。
- **水墨界面**：毛笔光标、砚台起点、墨点与纸张终点，短笔触尾迹和笔旁墨量提示。
- **三档难度**：普通、地狱、神仙；可查看完整参考路线，也能自由选择节点顺序。
- **轻量控制**：图标悬浮栏可拖动，鼠标右键或 Esc 随时退出。
- **本地运行**：页面分析与截图都在浏览器内完成，不上传数据，无广告与统计追踪。

## 安装

1. 从 [Releases](https://github.com/KINO-L/PagePath/releases) 下载 `PagePath-v1.0.0.zip`，解压到一个固定目录。
2. 打开扩展管理页：Chrome 输入 `chrome://extensions`，Edge 输入 `edge://extensions`。
3. 开启「开发者模式」，选择「加载已解压的扩展程序」，选中包含 `manifest.json` 的目录。
4. 在浏览器工具栏固定 PagePath，打开普通网页，点击扩展图标开始。

浏览器不能直接加载 ZIP；安装后请保留解压目录。也可以下载或克隆本仓库，直接加载仓库根目录。使用扩展不需要安装 Node.js。

## 玩法

从 **砚台**按住鼠标左键，在墨水耗尽前经过全部 **墨点**，最后进入 **纸张**。中间节点顺序不限，路线可以自交；碰到网页内容、提前松手或离开视口会失败。笔尖是实际判定位置，笔旁数字表示剩余墨水。

悬停工具栏图标可查看功能说明：**提示**显示参考路线，**重试**保留当前关卡，**新地图**更换布局。拖动左侧六点手柄可移动悬浮栏。**鼠标右键、Esc 或再次点击扩展图标**即可退出。

| 难度 | 通常的节点总数¹ | 相对参考路线的墨水余量 |
| --- | ---: | ---: |
| 普通 | 10–12 | 22% |
| 地狱 | 14–16 | 23.5% / 25% / 26.5%，随实际点数调整 |
| 神仙 | 14–16 | 10% |

¹ 包含起点和终点。页面空间不足时会减少节点；三档难度都使用相同碰撞范围和 45px 笔触尾迹。地狱在 5 点以内保留 10% 余量，之后每多一点增加 1.5 个百分点。墨水按实际绘制距离消耗，隐藏的旧笔迹仍计入用墨。

更详细的操作、更新方法与常见问题见 [使用指南](docs/USAGE.md)。

## 隐私与权限

扩展仅申请 `activeTab` 和 `scripting`，在你点击图标后分析当前页面。截图、节点和路线仅供本局使用，不保存为文件、不上传，退出时释放。没有账号、后端、遥测或浏览记录读取功能。详见 [隐私说明](docs/PRIVACY.md)。

静态画面只固定游戏所见的画面，网站自己的脚本、网络请求和音视频仍可能运行。

## 适用范围

- 面向桌面浏览器和鼠标操作，只使用当前视口；暂不支持手机、Firefox、Safari 或整页滚动关卡。
- 浏览器系统页、扩展商店和内置 PDF 阅读器等受限页面无法运行。
- 留白不足、页面结构过于复杂或特殊 CSS 效果可能导致无法生成关卡或边界近似。
- 调整窗口大小或浏览器缩放后需重新生成；绘制过程中切换窗口或标签页也会暂停。

参考路线经过安全检查，但不保证是数学上的最短路线。真实网页的视觉边界可能与分析得到的几何边界略有差异。

## 开发与反馈

源码采用原生 JavaScript、SVG 和 Manifest V3，无需打包编译。仓库保留 `src/`、`tests/` 与 `scripts/`，开发和测试方法见源码中的 `docs/DEVELOPMENT.md`；发行 ZIP 仅包含扩展运行文件和使用文档。

发现问题或有玩法建议，欢迎提交 [Issue](https://github.com/KINO-L/PagePath/issues)。请附上扩展版本、浏览器版本、操作步骤，以及可公开的页面地址或截图。
