# PagePath · 网页一笔画

**The webpage is the level. 网页就是关卡。**

PagePath 把当前网页变成水墨风格的一笔画游戏：文字、图片和图形成了障碍，页面留白成了通道。单击砚台开始，移动毛笔经过墨点，最后抵达纸张；也可以解锁「第二关」，在网页迷宫中探索出口。

**v2.0.0** · 桌面 Chrome / Edge · 本地运行 · 无需账号

## 特点

- **网页生成地图**：视口截图由本地 OpenCV 分析，小型 DOM 元素辅助合并障碍，保留真实视觉轮廓。
- **单击开始绘制**：点击砚台后直接移动鼠标，无需按住；笔旁显示墨量，靠近障碍时出现红色碰撞边界。
- **四种难度**：三档有限墨水的一笔画，加上无限墨水的网页迷宫。
- **静态游戏画面**：启动时定格视口；新地图复用截图，重新安排关卡。
- **简洁水墨界面**：毛笔、砚台、墨点、纸张与短笔触尾迹；悬浮栏可拖动，绘制时自动折叠。
- **本地处理**：无需服务器，不上传网页或游戏数据，无广告与统计追踪。

## 安装

1. 从 [Releases](https://github.com/KINO-L/PagePath/releases) 下载 ZIP，解压到固定目录。
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启「开发者模式」。
3. 选择「加载已解压的扩展程序」，选中包含 `manifest.json` 的目录。
4. 固定 PagePath 图标，打开普通网页，点击图标开始。

浏览器需要保留解压目录，不能直接加载 ZIP。也可克隆仓库后加载根目录；使用扩展无需安装 Node.js。

## 玩法

单击 **砚台**，鼠标会变成毛笔。直接移动，经过所有 **墨点** 后到达 **纸张**。墨点顺序不限，路线允许交叉；碰到障碍、离开视口或墨水耗尽会失败。失败或完成后恢复普通鼠标。

| 难度 | 通常的节点数（含起终点） | 墨水余量 |
| --- | ---: | ---: |
| 萌新 | 12–14 | 参考路线的 15% |
| 糕手 | 16–18 | 参考路线的 10%–11%，按实际点数调整 |
| 神仙 | 18–20 | 参考路线的 4% |
| 第二关 | 2 | 无限 |

前三档空间不足时会减少节点；**提示**只显示参考路线，**重试**保留关卡，**新地图**更换布局。墨水按实际移动距离消耗。

「第二关」需要原网页障碍占视口至少 **20%**，且内容分布达到 **30/48**。锁图标上的「复杂度」「分散度」以勾叉显示达标情况，解锁后变为五角星。迷宫沿原网页空隙生成，以细线连接障碍、形成唯一的起终点通路。新增墙线靠近时才显现，墨水无限，需自行探索，没有答案提示。

拖动悬浮栏左侧手柄可移动它。**鼠标右键、Esc、退出按钮或再次点击扩展图标**均可退出。完整操作与更新方法见 [使用指南](docs/USAGE.md)。

## 隐私与适用范围

扩展只申请 `activeTab` 和 `scripting`，在点击图标后分析当前页面。截图、地图和路线保留在本次游戏内存中，不上传、不存档；退出时释放。详见 [隐私说明](docs/PRIVACY.md)。

面向桌面 Chrome / Edge 和鼠标操作，只使用当前视口。浏览器系统页、扩展商店等受限页面无法运行；密集纹理、低对比内容或留白不足可能影响地图质量。窗口大小或缩放变化后需重新生成，绘制时切换窗口或标签页会暂停。定格画面不会停止网站自己的脚本、网络请求或音视频。
