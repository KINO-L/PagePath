# 迷页 · 网页迷宫

**The webpage is the level. 网页就是关卡。**

迷页把当前网页变成火苗探索迷宫：页面内容成为障碍，留白成为通道。单击小火堆，带着火苗探索路线，抵达出口洞口后获得积分和升级经验。

**v3.1.0** · 桌面 Chrome / Edge 109+ · 本地运行 · 无需账号

## 特点

- **各种页面都能成为迷宫**：截图由本地 OpenCV 分析，小型 DOM 元素辅助合并障碍；没有页面复杂度或面积解锁要求，必要时局部打通通道。
- **全范围随机难度**：所有页面都有机会生成 1–5 星，简单页面偏向低星，复杂页面偏向高星；星级根据最终路线长度、有效转弯和沿途岔路核验。
- **自由探索**：点击起点后直接移动，无需按住鼠标；没有移动距离限制或答案提示。靠近障碍时显示红色碰撞边界。
- **探索与成长**：通道中藏有靠近才显现的经验泡泡，每图必有一个随机倍率泡泡，持续显示柔和呼吸光。得分由迷宫实际难度决定，通关经验结合收集奖励和倍率计算，立即计入等级并自动保存。
- **火苗探索**：从小火堆出发，带着温暖的小火苗和短火星尾迹寻找出口洞口。启动时定格网页，悬浮栏可拖动，探索时自动折叠。
- **后台生成**：迷宫计算在独立线程运行，悬浮栏显示加载转圈，生成期间也可右键、按 Esc 或点击退出，立即停止本次生成。
- **多语言**：简体中文、日文和英文，自动跟随浏览器界面语言；其他语言默认使用英文。品牌名统一为「迷页」。

## 安装

1. 下载 [Miye-v3.1.0.zip](https://github.com/KINO-L/PagePath/releases/download/v3.1.0/Miye-v3.1.0.zip) 并解压，也可克隆本仓库。
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启「开发者模式」。
3. 选择「加载已解压的扩展程序」，选中包含 `manifest.json` 的目录。
4. 打开普通网页，点击迷页图标开始。

保留安装目录；浏览器不能直接加载 ZIP。使用扩展无需 Node.js 或构建步骤。

更新时退出游戏，用新版本替换原安装目录的文件，在扩展管理页点击「重新加载」，再刷新网页。v3.1.0 需要 Chrome / Edge 109+，新增 `offscreen` 权限承载扩展内部的本地计算线程；如浏览器提示权限变更，确认后重新启用扩展。

已有累计经验、成绩与结算记录保留，等级按新的五级曲线重新计算。请保留同一安装目录和扩展安装，避免卸载清除本地进度。

## 玩法

查看本局星级，单击 **小火堆** 开始，沿通道带着火苗移动到 **出口洞口**。火苗底部的亮点是实际位置，火焰和火星尾迹仅作装饰。只有起点和终点，可以回头探索；碰到障碍或离开视口会失败。失败、结束后恢复普通鼠标，重新点击小火堆即可同图重试。

**新地图**复用当前截图生成新迷宫；**重试**保留地图并重置本次泡泡收集。通关经验为 **（难度基础经验＋泡泡经验）×倍率**，同一张地图只奖励首次通关，之后可练习。等级共五级：萌新、糕手、吴迪、？？？、宇宙超级无敌螺旋牛逼；前期升级快，后期逐渐放慢，累计 150,000 经验满级。泡泡数量、概率和经验规则见 [使用指南](docs/USAGE.md)。

拖动悬浮栏可调整位置。**鼠标右键、Esc、退出按钮或再次点击扩展图标**均可退出。操作、计分和称号见 [使用指南](docs/USAGE.md)。

## 隐私与适用范围

截图和地图仅在本次游戏内存中处理，不上传网页、截图或地址。扩展使用 `storage` 在当前浏览器本地保存经验、成绩和近期结算记录，不使用云同步。详见 [隐私说明](docs/PRIVACY.md)。

支持桌面 Chrome / Edge 的普通网页，只使用当前视口；浏览器系统页、扩展商店等受限页面无法运行。窗口大小或缩放变化后需重新生成，探索时切换窗口或标签页会暂停。定格画面不会停止原网站的脚本、网络请求或音视频。
