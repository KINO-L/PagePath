# 隐私说明

本说明适用于 PagePath v1.0.0。

## 本地处理

PagePath 在你点击扩展图标后，分析当前视口中的网页元素，并获取当前视口截图，用于生成和显示一笔画关卡。页面几何、截图、节点、路线和本局成绩都在浏览器内处理。

扩展不上传网页文字、DOM、页面地址、截图或游戏数据，不发起网络请求，没有账号、服务器、广告、统计追踪或第三方分析服务，也不读取浏览历史。

## 权限用途

| 权限 | 用途 |
| --- | --- |
| `activeTab` | 在用户点击图标后，临时访问当前标签页并截取可见区域 |
| `scripting` | 将本地游戏代码按需注入当前网页 |

扩展不申请所有网站的常驻访问权限，不在页面载入时自动开始游戏。本地文件只有在用户自行开启「允许访问文件网址」后才可使用。

## 数据生命周期

截图不保存成文件，关卡与最近几张地图的节点位置只保留在本次游戏的内存中。退出时释放本局截图和游戏状态，重新截图时释放旧截图。没有云同步、存档或跨局成绩记录。

静态画面不影响原网站自己的数据处理：它的脚本、网络请求、音视频和后台更新仍可能继续运行。PagePath 的本地处理说明仅针对扩展本身。

## 反馈

隐私相关问题可以通过 [项目 Issues](https://github.com/KINO-L/PagePath/issues) 反馈。Issue 内容由你主动提交给 GitHub；请勿上传包含私人信息的网页截图或页面内容。
