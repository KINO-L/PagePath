# 使用指南

PagePath v2.0.0 将当前网页截图变成水墨风格的一笔画或迷宫关卡。

## 安装与更新

1. 从 [Releases](https://github.com/KINO-L/PagePath/releases) 下载 ZIP 并解压。
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择含 `manifest.json` 的目录。
4. 保留安装目录，并把 PagePath 固定到浏览器工具栏。

更新时先退出游戏，将新版本解压到原安装目录，在扩展管理页点击 PagePath 的「重新加载」，最后刷新已打开的网页。换了安装目录时，需重新选择目录加载。

## 开始游戏

1. 打开普通网页，停在想玩的区域，点击 PagePath 图标。
2. 等待截图分析和节点出现。每次启动默认萌新难度。
3. 单击砚台，鼠标变成毛笔；无需按住，直接移动经过所有墨点，再到达纸张。
4. 避开障碍，留意笔旁墨量。靠近障碍时，红色轮廓会逐渐变明显。
5. 完成后可重试或换图；右键或 Esc 退出。

墨点顺序不限，路线可以交叉。集齐墨点后到达终点才会完成。毛笔笔尖是实际绘制与碰撞位置，笔杆仅为外观。

碰撞、离开视口、输入取消或墨水用尽会失败，随后准备同图重试。开始前及失败、完成后显示普通鼠标，重新单击砚台即可再试。

## 悬浮栏

| 操作 | 效果 |
| --- | --- |
| 难度图标 | 单峰为萌新、双峰为糕手、三峰为神仙；第二关未解锁为锁，解锁为五角星。点击切换难度并生成新图 |
| 提示 / 收起 | 前三档显示或隐藏参考路线与节点顺序，不显示全图障碍；第二关没有此按钮 |
| 重试 | 保留地图，清空本次轨迹并恢复墨水 |
| 新地图 | 复用当前静态网页，重新生成关卡；原障碍轮廓短暂高亮一次 |
| 重新生成 | 暂停后重新截取网页并生成关卡 |
| 左侧六点手柄 | 拖动悬浮栏；栏内空白处也可拖动 |
| 退出 | 结束游戏，恢复网页操作 |

绘制时悬浮栏折叠为小短横，成功、失败或暂停后展开。绘制和生成期间不能拖动或切换难度；绘制时也不能切换提示。前三档可先打开路线再开始，同图重试保留提示，新图、换难度或暂停会清除提示。

移动悬浮栏不耗墨、不换图。手柄获得键盘焦点后，方向键移动 8px，Shift + 方向键移动 24px。Tab 可切换控件焦点，Enter 或空格触发按钮。

鼠标右键、Esc、退出图标、再次点击浏览器工具栏中的 PagePath 图标，都可以退出。游戏内右键不会弹出网页菜单。

## 难度与墨水

| 难度 | 通常的节点总数 | 墨水预算 |
| --- | ---: | --- |
| 萌新 | 12–14 | 参考路线长度 × 1.15 |
| 糕手 | 16–18 | 参考路线长度 × [1.06 + max(0, N − 8) × 0.005] |
| 神仙 | 18–20 | 参考路线长度 × 1.04 |
| 第二关 | 2 | 无限，笔旁显示 ∞ |

N 包含起点和终点。前三档在空间不足时会减少节点，最少 4 个；糕手按实际点数计算预算，16、17、18 点分别有 10%、10.5%、11% 的额外墨水。

墨量按鼠标实际移动距离扣除，绕路、抖动和反复修正都会耗墨。100% 表示整份预算，低于或等于 20% 时变为朱砂色。各模式只显示最近 45px 的笔触，旧笔迹消失不返还墨水。参考路线是可行解，不保证最短。

## 第二关：网页迷宫

第二关按当前视口的两项数据解锁：

- **复杂度**：原网页障碍占视口至少 20%。
- **分散度**：视口分为 8×6 共 48 格，至少 30 格含有足够内容；每格障碍占约 10% 即计入。

未解锁时悬停锁图标，会看到「寻找复杂的页面来解锁第二关。」及两项指标的勾叉，绿色 ✓ 为达标，红色 ✕ 为未达标。可以退出后滚动到其他区域，或换一个内容更丰富的页面。达标后图标变为五角星。

迷宫先合并相邻的小障碍，再沿网页空间规划路线，以细斜线或折线连接障碍、封住绕行通道。必要时局部打通原障碍，保持起终点之间可通行。迷宫只有砚台和纸张，墨水无限，可以回头探索；碰到障碍或隐藏墙线仍会失败。

第二关没有答案提示。新增墙线平时透明，靠近时显示红色碰撞边界；新图闪烁只显示原障碍。「重试」保留迷宫，「新地图」重新选择路线和连接。切回前三档恢复原网页地图。重新截图后会重新检查解锁条件。

## 页面定格与暂停

启动时使用固定截图和障碍地图，网页动画与后台更新不会移动本局节点；游戏期间滚轮滚动被拦截。网站自己的脚本、网络请求和音视频仍可能运行，退出后恢复实时页面。

窗口尺寸或浏览器缩放变化后需重新生成；绘制时切换窗口或标签页会暂停。触控板双指放大后，请恢复手势缩放再启动。

## 常见问题

**点击图标后无法开始，图标出现 `!`。**

浏览器系统页、扩展商店和内置 PDF 阅读器等页面限制扩展运行，请换普通网页。本地 HTML 需在扩展详情中开启「允许访问文件网址」。

**页面空白不足，无法生成普通关卡。**

退出后换个页面位置。第二关指标达标时，仍可点击五角星进入迷宫。

**看起来没碰到内容，却撞到了。**

红色轮廓包含笔尖和安全留白，是实际碰撞边界。非常窄的空隙可能无法通过；封闭在障碍内部、从起点不可达的小区域不显示轮廓。

**浅线可以穿过，或某些图形被当作背景。**

图像分析会过滤低对比装饰细线。均匀色块与背景、低对比内容与留白有时难以区分；复杂照片和密集纹理可能影响地图质量。

**网页更新了，「新地图」却还是旧画面。**

「新地图」复用截图，只改变关卡布局。退出后重新启动即可使用最新网页。

**墨水突然恢复到 100%。**

本次尝试已失败，系统正在准备同图重试。

**更新扩展后仍是旧界面。**

重新加载扩展，再刷新已打开的网页。

问题可提交到 [Issues](https://github.com/KINO-L/PagePath/issues)，请附版本、浏览器及复现步骤，遮盖截图中的私人信息。
