# 使用指南

PagePath v1.0.0 把当前网页的可见区域变成一笔画关卡。建议先在留白较多的普通网页上试一局。

## 安装与更新

1. 在 [Releases](https://github.com/KINO-L/PagePath/releases) 下载发行 ZIP 并解压。
2. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择含 `manifest.json` 的目录，然后把 PagePath 固定到浏览器工具栏。

安装后请保留这个目录。ZIP 本身不能直接加载，使用扩展也不需要运行仓库中的开发脚本。

更新时先退出游戏，将新版本解压到原安装目录，再在扩展管理页点击 PagePath 的「重新加载」。最后刷新之前已打开的网页。若换了安装目录，需重新选择该目录加载。

## 完成第一局

1. 打开一个普通 HTTP / HTTPS 网页，停在想玩的区域。
2. 点击 PagePath 图标，保持当前标签页在前台，等待页面定格和节点出现。
3. 在砚台上按住鼠标左键，经过所有墨点后到达纸张。
4. 中途保持按住，避开文字、图片、按钮等网页内容，并留意笔旁墨水百分比。
5. 到达终点后可重试或换图；鼠标右键或 Esc 退出游戏。

墨点可以任意顺序经过，路线允许交叉。必须集齐其他节点后再进入终点；提前路过终点不会完成。毛笔笔尖是绘制与碰撞位置，倾斜的笔杆只是外观。

碰撞、松手、离开视口、输入取消或墨水用尽会失败，随后自动恢复到待开始状态。也可直接重新从砚台按下开始。

## 悬浮栏

图标上悬停可查看名称、状态和说明，Tab 可以在控件之间移动焦点。

| 操作 | 效果 |
| --- | --- |
| 难度选择 | 切换普通、地狱或神仙，生成对应的新关卡 |
| 提示 / 收起 | 显示或隐藏完整参考路线、方向箭头和节点顺序 |
| 重试 | 保留地图，清空本次轨迹并恢复墨水 |
| 新地图 | 沿用同一张静态网页，重新生成节点布局 |
| 重新生成 | 暂停后出现，重新截取当前网页并生成关卡 |
| 左侧六点手柄 | 拖动悬浮栏；栏内空白区域也可以拖动 |
| 退出 | 移除游戏，恢复网页操作 |

绘制和生成期间不能拖动悬浮栏或切换难度，绘制时也不能切换提示。可以先打开提示，再从砚台开始练习。提示不补充墨水，也不会代替收集节点；同图重试保留提示，新图、切换难度或暂停会清除提示。

移动悬浮栏不换图、不耗墨。键盘聚焦拖动手柄后，方向键每次移动 8px，Shift + 方向键每次移动 24px；悬浮栏会保持在窗口内。若它遮住节点，开始前先把它移开。

**退出方式**：在游戏画面内点击鼠标右键、按 Esc、点击退出图标，或再次点击浏览器工具栏中的 PagePath 图标。右键退出时不会弹出网页菜单。

## 难度与墨水

| 难度 | 空间充足时的节点总数 | 墨水预算 |
| --- | ---: | --- |
| 普通 | 10–12 | 参考路线长度 × 1.22 |
| 地狱 | 14–16 | 参考路线长度 × [1.10 + max(0, N − 5) × 0.015] |
| 神仙 | 14–16 | 参考路线长度 × 1.10 |

N 是最终生成的节点总数，包含砚台和纸张。空间不足时会减少节点，最少 4 个；地狱也按这些实际节点计算预算。14、15、16 点分别对应 23.5%、25%、26.5% 的额外墨水。悬停难度图标可查看本局实际点数和余量。

例如，地狱生成 15 点、参考路线长 3000px 时，可用墨水为 3750px。笔旁的 100% 表示这整份预算，不是只表示额外余量。低于或等于 20% 时数字变为朱砂色。

鼠标实际走过的每段距离都会扣墨，绕路、抖动和反复修正会增加消耗。三种难度都只显示最近 45px 的笔触，旧笔迹消失不会返还墨水。提示显示的路线与计算预算的路线一致，可作为规划参考；它不保证是最短解。

每次启动默认普通难度，退出后不保存上次难度、成绩或关卡。

## 页面定格与暂停

启动时，PagePath 在本地截取当前视口，随后使用固定画面和障碍地图。广告、计时器、动画或页面后台更新不会挪动已生成的节点，也不会因此打断游戏。游戏期间滚轮滚动暂时被拦截。

这不会停止网站自己的脚本、网络请求或音视频。退出后会看到网页的实时状态。窗口尺寸、浏览器缩放变化会改变地图坐标，因此仍需重新生成；绘制中切到其他窗口或标签页也会暂停。

## 常见问题

**点击后没有游戏，图标出现 `!`。**

当前页面可能不允许扩展运行。请换到普通网页；浏览器系统页、扩展商店和内置 PDF 阅读器均有访问限制。本地 HTML 文件需要先在扩展详情中开启「允许访问文件网址」。

**提示空白不足，无法生成地图。**

退出后滚动到留白更多的位置，或换一个页面。扩展需要一片足以连接节点的可通行空间，不能保证每个视口都有合适的关卡。

**总是在同一处撞到内容。**

观察毛笔笔尖与网页内容的距离，也可以打开提示确认参考走法。复杂变换、裁剪、伪元素、画布和内嵌页面可能使视觉边界与检测边界有差异。

**地图像没变，网页明明已经更新。**

「新地图」有意复用当前静态画面，只改变节点布局。想使用更新后的网页时，退出后重新启动。

**墨水忽然从低值变回 100%。**

尝试已经失败，系统自动准备同一地图供重试。悬停状态图标可以查看当前提示；墨水用尽与碰撞等失败都会进入重试流程。

**更新扩展后仍是旧界面。**

在扩展管理页重新加载 PagePath，再刷新已打开的网页，随后重新启动游戏。

其他问题可提交到 [Issues](https://github.com/KINO-L/PagePath/issues)。请说明版本、浏览器、复现步骤，以及是否使用了提示路线；公开截图前先遮盖网页中的私人信息。
