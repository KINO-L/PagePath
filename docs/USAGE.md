# 使用指南

迷页 v3.1.0 将当前网页截图变成火苗探索迷宫。

需要桌面 Chrome / Edge 109 或更新版本，使用 `offscreen` 权限承载扩展内部的本地迷宫计算；不增加网站访问权限。

## 安装与更新

下载 [Miye-v3.1.0.zip](https://github.com/KINO-L/PagePath/releases/download/v3.1.0/Miye-v3.1.0.zip) 并解压，或克隆仓库。在 `chrome://extensions` 或 `edge://extensions` 开启「开发者模式」，选择「加载已解压的扩展程序」，选中含 `manifest.json` 的目录。

更新时退出游戏，将新版本替换到原安装目录，在扩展管理页点击「重新加载」，再刷新网页。保留原扩展安装，避免卸载导致本地等级和成绩清除。

v3.1.0 新增 `offscreen` 权限，使迷宫生成在扩展内部的本地线程中运行；`storage` 继续用于保存等级和成绩。如浏览器提示权限变更，确认后重新启用扩展。已有累计经验、成绩与结算记录完整保留，等级按新的五级曲线重新计算。

进度属于当前浏览器内的扩展安装。请在同一目录替换文件并重新加载，不要卸载；更换目录或重新安装可能创建新的扩展身份，无法继续读取原来的进度。

界面支持简体中文、日文和英文，自动跟随浏览器界面语言（通常与系统语言一致），不受当前网页语言影响。中文语言环境统一显示简体中文，其他未支持的语言使用英文。更改浏览器语言并按浏览器要求重启后，重新打开游戏即可生效；语言切换不影响等级和经验。

## 开始游戏

1. 打开普通网页，停在想玩的区域，点击迷页图标。
2. 悬浮栏显示转圈时正在生成随机迷宫，完成后显示难度星级。生成中也可右键、按 Esc 或点击退出，立即取消。
3. 单击小火堆，鼠标变成一簇小火苗；无需按住，移动到出口洞口即通关。
4. 靠近障碍时留意红色轮廓。移动距离不限，可以回头探索，没有答案提示。
   通道中还藏有经验泡泡，经过即可收集；每图必有一个随机倍率泡泡，持续显示柔和呼吸光。
5. 通关后在同一悬浮栏内查看获得的经验和等级，也可换图继续。

所有页面共用这套玩法，没有障碍面积或内容分布的解锁条件。生成器会利用原页面的通道和障碍；空白或密集页面也会补充细墙，必要时局部打通原障碍，保证起终点有唯一通路。

火苗底部的亮点是实际鼠标位置和碰撞位置，火焰和短火星尾迹仅作装饰。碰撞、离开视口或输入取消会失败，随后准备同图重试。开始前以及失败、完成后恢复普通鼠标，重新单击小火堆即可再试。

## 悬浮栏

| 操作 | 效果 |
| --- | --- |
| 重试 | 保留地图，回到起点，重置本次泡泡收集 |
| 新地图 | 复用当前静态截图，重新生成随机迷宫 |
| 重新生成 | 暂停后重新截取网页并生成迷宫 |
| 拖动手柄或栏内空白处 | 移动悬浮栏 |
| 退出 | 结束游戏，恢复网页操作 |

悬浮栏在开始前显示本局星级，通关后原位显示「+经验」，立即计入等级，并保留称号和经验进度。探索时折叠为本次收集经验与倍率，成功、失败或暂停后展开。探索和生成期间不能拖动悬浮栏。

手柄获得键盘焦点后，方向键移动 8px，Shift + 方向键移动 24px。Tab 切换控件焦点，Enter 或空格触发按钮。

鼠标右键、Esc、退出图标、再次点击浏览器工具栏中的迷页图标，都可以退出；游戏内右键不会弹出网页菜单。

## 泡泡与经验

所有页面都有机会生成 1–5 星。简单页面更容易出现低星，复杂页面更容易出现高星；简单页面也能遇到五星，复杂页面也能遇到一星。生成器按抽中的目标调整路线和岔路，再根据最终路线长度、有效转弯和沿途的探索分支核验实际星级。点击「新地图」会重新随机。

每图目标生成 4～10 个经验泡泡，星级越高，目标数量越多；空间不足时会减少数量。每个泡泡的经验独立抽取：10 经验占 60%，20 经验占 30%，40 经验占 10%。泡泡只放在起点能够到达的通道内。

每图必定出现一个倍率泡泡，倍数随机抽取，概率如下。通道较窄时会缩小泡泡，保证能够拾取。

| 倍率 | 出现概率 |
| --- | ---: |
| ×2 | 62.5% |
| ×3 | 25% |
| ×5 | 10% |
| ×8 | 2.5% |

经验泡泡靠近且中间没有墙时才显现，所有倍率泡泡始终带柔和呼吸光。经过泡泡会累积本次经验或激活倍率，未吃到倍率时按 ×1 结算，通关后统一发放。失败或重试会还原泡泡并重置收集；完成后再次练习不重复奖励。

实测难度分值为 `D`（0～100），通关得分为 `600 + 20 × D`、四舍五入取整，难度基础经验为得分的十分之一、四舍五入。**最终经验 =（难度基础经验 + 收集经验）×倍率**。例如难度 50、收集 40 经验并吃到 ×3，通关获得 `(160 + 40) × 3 = 600` 经验。用时和失败次数不影响奖励。

## 等级与称号

同一张地图只结算一次奖励。等级共五级，前期升级快，后期逐渐放慢。已有累计经验完整保留，更新后按下表重新计算等级。

| 等级 | 称号 | 所需累计经验 | 升至下一级所需经验 |
| ---: | --- | ---: | ---: |
| 1 | 萌新 | 0 | 1,500 |
| 2 | 糕手 | 1,500 | 13,500 |
| 3 | 吴迪 | 15,000 | 45,000 |
| 4 | ？？？ | 60,000 | 90,000 |
| 5 | 宇宙超级无敌螺旋牛逼 | 150,000 | 已满级 |

按平均每次新地图通关获得 500 经验、包含失败重试在内平均每次通关用时 4 分钟估算，累计约 20 小时满级。实际进度取决于地图难度、收集和倍率；用时不参与奖励计算。

等级和成绩自动保存在当前浏览器的扩展本地存储中，无需手动确认；关闭页面或浏览器后保留，不跨设备同步。卸载扩展会清除进度。

## 页面定格与暂停

启动时使用固定截图和障碍地图，网页动画与后台更新不会移动本局迷宫；游戏期间拦截滚轮滚动。「新地图」复用截图，要更新网页画面可退出后重新启动。

窗口尺寸或浏览器缩放变化后需重新生成；探索时切换窗口或标签页会暂停。触控板双指放大后，请恢复手势缩放再启动。原网站的脚本、网络请求和音视频仍可能运行。

## 常见问题

**点击图标后无法开始。** 浏览器系统页、扩展商店和内置 PDF 阅读器等页面限制扩展运行，请换普通网页。本地 HTML 需在扩展详情中开启「允许访问文件网址」。

**看起来没有碰到内容，却失败了。** 红色轮廓包含火苗底部亮点的碰撞半径和安全留白，代表实际碰撞边界；新增细墙平时透明，靠近时才显示。从起点不可达的内部小区域不显示轮廓。

**浅色线条可以穿过。** 图像分析会过滤低对比装饰细线，均匀色块和复杂照片也可能与视觉预期不同；以附近显示的碰撞边界为准。

**更新后仍是旧界面。** 重新加载扩展，再刷新已打开的网页。

问题可提交到 [Issues](https://github.com/KINO-L/PagePath/issues)，请附版本、浏览器及复现步骤，遮盖截图中的私人信息。
